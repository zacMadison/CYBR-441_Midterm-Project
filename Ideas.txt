Goal: produce a functional, clean, and useful application that embeds AI.

Current Ideas:
  Vs AI: make AI play a simple game against a real human player via API calls with a system prompt that enforces inclusion of a response with a specific format (Could also include AI thought process as extra)
    Can be done via python, using pygame, or as a webpage using html, css, and js

  Endpoint summarize: Summarize API endpoints for an end user. Good example would be the weather.com API 

  AIdle: Have multiple AI models and generic prompts, choose a random prompt and a random model and have the user try to guess which model it is
    Would involve webdev, largest challenge would be finding multiple models with free APIs
